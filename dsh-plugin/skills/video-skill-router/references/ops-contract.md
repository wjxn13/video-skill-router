# ops 契约（编排硬规则与交付标准）

执行层（multi-tool-video-pipeline 等）必须遵守本节全部规则。这些是**可回归校验**的硬约束，不是建议。

## 1. A/V 同步硬规则

1. **每段视频时长 = 该段旁白实测时长**。旁白长就延展视频，绝不裁旁白。
2. 旁白按段分别生成，并**实测 mp3 时长**（用 `ffprobe`/`duration()` 读，不信赖估算），该实测时长就是该段视频长度基准。
3. 段间交叉淡化 0.5–1s，不挤压旁白内容。
4. 合成后**抽帧 + 测各段起止时间戳**核对落点；下游锚点随旁白超槽累加顺延。

## 2. 依赖顺序（先做什么后做什么）

```
Edge TTS 出底音（测时长定段长）
    → (可选) DDSP 换音色（内容不变，仅改音色）
    → 各段按实测时长渲染
    → ffmpeg xfade 视频总装 + acrossfade 音频总装
    → 字幕烧录 / 软字幕轨
```

**先 TTS 定段长，再渲染**——反过来会让所有下游锚点漂移。

## 3. 交付物标准

- 分辨率/帧率/pix_fmt 全段统一（默认 1080p 30fps yuv420p）。
- 有字幕时**双交付**：软字幕版（mov_text 轨，可开关）+ 硬烧版（字焊画面）。两版同帧 md5 不同即证明字幕已烧入。
- 总成片时长 == Σ段时长 − Σ crossfade（A/V 同步硬指标）。

## 4. 校验门禁（交付前必跑）

- [ ] 成片总时长 == Σ段时长 − Σcrossfade
- [ ] 逐段起点抽帧，文件大小各异（动画在播，非静帧）
- [ ] 每段关键帧视觉检查通过（布局/颜色/水印/文字如脚本描述）
- [ ] 音频峰值 < 0 dB（无削波）
- [ ] 字幕轨存在（或 SRT 已出）
- [ ] 各段分辨率/帧率/pix_fmt 一致

> 读图失效时用 PIL 像素扫描等价核对：① 底部白像素最高行推字幕带高度（应 <200px）；② 按 RGB 阈值统计颜色元素；③ 多帧 md5 互异确认动画在播。
