# DDSP 音色转换（自定义/克隆音色）

## 定位

DDSP（DDSP-SVC / SVC Fusion）是**音色转换层**，不吃文本、不出词。它把一段底音（已有语音）转换成目标音色，不改内容。用于在 Edge TTS 预设声线之外扩充自定义/克隆音色。

## 标准流程（顺序不可反）

1. **训练音色模型**（离线，一次性）：用目标音色的干净音频（语音/歌声）训练 DDSP 模型，得到音色权重。
2. **出底音**：Edge TTS 生成底音（文本 → 语音），**实测底音时长**，作为该段视频长度基准。
3. **换音色**：用训练好的 DDSP 模型对底音做音色转换（voice conversion），得到自定义音色的配音。
4. **A/B 抽听校验**：转换后文本/节奏须与底音一致，仅音色改变。

## 契约

- `custom-voice-content-preserved`：换音色不改内容/节奏，需 A/B 抽听。
- 依赖顺序 `after-tts`：**必须先出底音定段长，再换音色**。反过来会破坏 A/V 同步锚点（底音时长是段长的来源）。

## 工具

- SVC Fusion（DDSP-SVC 整合包）：训练 + 推理，本地免付费 API。
- 本机已在多个视频验证（训练音色 → 对 TTS 底音换音色），详见本地 skill `svc-fusion`。

## 与 Edge TTS 的关系

- Edge TTS 提供**内容**（文本 → 语音）与**时长锚点**。
- DDSP 提供**音色**（音色转换）。
- 两者是接力关系，不是二选一：需要自定义音色时才走 DDSP，否则 Edge TTS 预设声线直接可用。
